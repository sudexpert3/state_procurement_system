## Специфика Gemini CLI

Правила проекта сюда не дублировать — им место в `AGENTS.md`.

- Отвечать и писать комментарии в коде **на русском языке**.
- Перед любой правкой прочитать `docs/CurrentStatus.md` и релевантные файлы из `docs/`.
- Перед тем как сказать «готово» — выполнить `npm run type-check && npm run lint` и показать вывод.
- Не выходить за пределы каталога `frontend/`.
