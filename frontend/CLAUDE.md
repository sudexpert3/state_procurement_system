## Специфика Claude Code

Ниже — только то, что касается Claude Code. Правила проекта сюда не дублировать, им место в `AGENTS.md`.

### Skills

- `/commit` — коммит + пуш после логического блока работы.
- `/worktree` — создать изолированный worktree, если работаешь параллельно с другими агентами (см. раздел «Параллельная работа» в `AGENTS.md`).
- `/code-review` — ревью текущего диффа перед коммитом.
- `/shadcn` — работа с UI-компонентами и реестрами shadcn.

### Субагенты

- `code-reviewer` — ревью реализованной фичи перед коммитом.
- `docs` — документация библиотек через Context7 (React Hook Form, Zod, TanStack, Zustand).
- `research` — **любой** веб-поиск и загрузка страниц идут только через него, не вызывать WebSearch/WebFetch напрямую.
- `Explore` — быстрый поиск по кодовой базе, когда неясно где лежит нужный код.

### MCP

Конфиг — в `.mcp.json`. Подключён `shadcn` MCP: поиск компонентов по реестрам и получение примеров использования.
