1. Создаем резервную копию: pg_dump -U sps sps_db > /var/lib/postgresql/backups/sps_db_backup.sql

2. Восстановление из резервной копии:
    2.1 Удаляем старую базу командой: psql -U sps -d postgres -c "DROP DATABASE sps_db;"
    2.2 Создайте новую, пустую базу данных командой: psql -U sps -d postgres -c "CREATE DATABASE sps_db ENCODING 'UTF8';"
    2.3. Восстанавливаем командой: psql -U sps -d sps_db -f /var/lib/postgresql/backups/sps_db_backup.sql
